STATISTICS 1 (S1) TOPICS

1. Representation of Data S1

1.1 Histograms

Key Points:
• Area = Frequency
• Height = Frequency Density = Frequency / Class Width
• No gaps between bars (continuous data)
• Frequency = Frequency Density × Class Width
Problem: A grouped frequency table for weights of adults:
Weight (kg)Frequency
50 - 6060
70 - 8520
In a histogram, the bar for 50-60 kg is 2 cm wide and 9 cm high. Find the width and height of the bar for 70-85 kg class.
Solution:
Width of 50-60 class = 10 kg ≡ 2 cm
⇒ Width of 70-85 class = 15 kg ≡ (15/10) × 2 = 3 cm

Area of 50-60 bar = 2 × 9 = 18 cm² ≡ frequency 60
⇒ Frequency of 70-85 bar = 20 ≡ area of (20/60) × 18 = 6 cm²
⇒ Height = area ÷ width = 6 ÷ 3 = 2 cm

1.2 Box-and-Whisker Plots

Five-figure summary:
1. Minimum value
2. Lower quartile (Q₁)
3. Median (Q₂)
4. Upper quartile (Q₃)
5. Maximum value

Skewness from Box Plots:
• Symmetrical: (Q₃ - Q₂) = (Q₂ - Q₁)
• Positive skew: (Q₃ - Q₂) > (Q₂ - Q₁)
• Negative skew: (Q₃ - Q₂) < (Q₂ - Q₁)

2. Measures of Location & Spread S1

2.1 Mean with Coding

If t = (x - k)/a, then:
• x̄ = at̄ + k
• sx = ast
• sx² = a²st²
Problem: Ages of 18 people: Σx = 745, Σx² = 33,951
(i) Calculate mean and standard deviation
(ii) One person leaves, mean of remaining 17 is 41. Find age of person who left and new s.d.
Solution:
(i) x̄ = 745/18 = 41.4 years
σ = √(Σx²/n - x̄²) = √(33951/18 - 41.4²) = 13.2

(ii) Total age of 17 people = 41 × 17 = 697
Age of person who left = 745 - 697 = 48 years

New Σx² = 33951 - 48² = 31,647
New σ = √(31647/17 - 41²) = 13.4

3. Probability S1

3.1 Independent Events

Events A and B are independent if:
P(A ∩ B) = P(A) × P(B)
Problem: A and B are independent. P(A) = 0.5, P(A ∩ B') = 0.3. Find P(B).
Solution:
P(A) = P(A ∩ B) + P(A ∩ B')
0.5 = P(A ∩ B) + 0.3
P(A ∩ B) = 0.2

Since A and B are independent:
P(A ∩ B) = P(A) × P(B)
0.2 = 0.5 × P(B)
P(B) = 0.2/0.5 = 0.4

3.2 Conditional Probability

P(A|B) = P(A ∩ B) / P(B)

4. Binomial Distribution S1

Conditions:
• Fixed number of trials (n)
• Only two outcomes (success/failure)
• Constant probability of success (p)
• Independent trials

Notation: X ~ B(n, p)

Formulas:
• P(X = x) = ⁿCₓ × px × (1-p)n-x
• E(X) = np
• Var(X) = np(1-p)

5. Normal Distribution S1

X ~ N(μ, σ²)

Standardize: Z = (X - μ) / σ

Properties:
• Symmetrical bell curve
• Mean = Median = Mode
• 68% within μ ± σ
• 95% within μ ± 2σ
• 99.7% within μ ± 3σ
Problem: Chocolate bars: W ~ N(205, 2.6²), stated weight 200g
(a) Find P(bar is underweight)
(b) 4 bars chosen. Find P(fewer than 2 underweight)
Solution:
(a) Z = (200 - 205)/2.6 = -1.923
P(W < 200) = P(Z < -1.92) = 1 - Φ(1.92) = 1 - 0.9726 = 0.0274

(b) Let p = 0.0274
P(0 underweight) = (0.9726)⁴ = 0.8957
P(1 underweight) = 4 × 0.0274 × (0.9726)³ = 0.1008
P(fewer than 2) = 0.8957 + 0.1008 = 0.997

5.1 Normal Approximation to Binomial

Conditions: np > 5 AND nq > 5
If X ~ B(n, p), then approximately X ~ N(np, npq)

Continuity Correction (e.g., x = 6):
BinomialNormal
x = 65.5 ≤ x ≤ 6.5
x > 6x ≥ 6.5
x ≥ 6x ≥ 5.5
x < 6x ≤ 5.5
x ≤ 6x ≤ 6.5

STATISTICS 2 (S2) TOPICS

6. Poisson Distribution S2

Notation: X ~ Po(λ)

Formula: P(X = x) = (e-λ × λx) / x!

Properties:
• E(X) = λ
• Var(X) = λ
• Mean = Variance (unique property!)

Conditions for Poisson:
• Events occur randomly
• Events occur singly (not simultaneously)
• Events occur independently
• Constant rate (mean proportional to interval)
Problem: Radioactive emissions: A ~ Po(0.65), B ~ Po(0.45) per minute
(i) Find P(≥3 emissions from A in 3 minutes)
(ii) Find P(<4 emissions from A and B together in 2 minutes)
Solution:
(i) A ~ Po(0.65 × 3) = Po(1.95)
P(A ≥ 3) = 1 - P(A ≤ 2)
= 1 - [e-1.95(1.95²/2! + 1.95¹/1! + 1.95⁰/0!)]
= 1 - 0.690 = 0.310

(ii) (A + B) ~ Po(2(0.65 + 0.45)) = Po(2.2)
P(A + B < 4) = P(A + B ≤ 3)
= e-2.2[2.2³/3! + 2.2²/2! + 2.2¹/1! + 2.2⁰/0!]
= 0.819

6.1 Addition of Poisson Distributions

If X ~ Po(λ) and Y ~ Po(μ) are independent, then:
X + Y ~ Po(λ + μ)

6.2 Poisson Approximation to Binomial

Conditions: n > 50 AND np < 5
If X ~ B(n, p), then approximately X ~ Po(np)

6.3 Normal Approximation to Poisson

Condition: λ > 15
If X ~ Po(λ), then approximately X ~ N(λ, λ)
Remember continuity correction!
Problem: Flaws in cloth: X ~ Po(0.04l) where l = length in meters
(i) Find P(< 2 flaws in 10m)
(ii) Approximate P(≥ 46 flaws in 1000m)
(iii) Cost = X² pence. Find expected cost for 1000m
Solution:
(i) λ = 0.04(10) = 0.4, X ~ Po(0.4)
P(X < 2) = e-0.4(0.4⁰/0! + 0.4¹/1!) = 0.938

(ii) λ = 0.04(1000) = 40 > 15, use normal approximation
X ~ Po(40) → Y ~ N(40, 40)
P(X ≥ 46) with continuity: P(Y ≥ 45.5)
Z = (45.5 - 40)/√40 = 0.870
P(Z ≥ 0.870) = 1 - 0.808 = 0.192

(iii) Var(X) = E(X²) - [E(X)]²
40 = E(X²) - 40²
E(X²) = 1640 pence = £16.40

7. Linear Combinations of Random Variables S2

For any random variables:
E(aX + bY + c) = aE(X) + bE(Y) + c

For independent random variables:
Var(aX + bY + c) = a²Var(X) + b²Var(Y)
Note: Var(X ± Y) = Var(X) + Var(Y)

Important distinction:
E(2X) = 2μ AND E(X₁ + X₂) = 2μ
BUT Var(2X) = 4σ² while Var(X₁ + X₂) = 2σ²
Problem: T has mean 5 and variance 16. Find c and d such that:
E(cT + d) = 100 and Var(cT + d) = 144
Solution:
E(cT + d) = cE(T) + d = 5c + d = 100 ... (1)

Var(cT + d) = c²Var(T) = 16c² = 144
c² = 9, so c = ±3

From equation (1):
If c = 3: d = 100 - 15 = 85 → (c, d) = (3, 85)
If c = -3: d = 100 + 15 = 115 → (c, d) = (-3, 115)

8. Continuous Random Variables S2

8.1 Probability Density Function (pdf)

Properties:
• ∫ f(x)dx = 1 (total area = 1)
• f(x) ≥ 0 (no negative probabilities)
• P(a < X < b) = ∫ab f(x)dx
• P(X = b) = 0 (no area at a point)
• Mode = maximum point of f(x)
Mean: E(X) = ∫ xf(x)dx
Variance: Var(X) = E(X²) - [E(X)]²
where E(X²) = ∫ x²f(x)dx

Median: Value m where ∫-∞m f(x)dx = 0.5
Problem: f(x) = kx(6-x) for 2 < x < 5, otherwise 0
(i) Find k
(ii) Find mode
(iii) Find P(X < mode)
Solution:
(i) ∫25 kx(6-x)dx = 1
[3kx² - kx³/3]25 = 1
75k - 125k/3 - 12k + 8k/3 = 24k = 1
k = 1/24

(ii) f'(x) = k(6 - 2x) = 0
x = 3 → Mode = 3

(iii) P(X < 3) = ∫23 (x/24)(6-x)dx
= [3x²/24 - x³/72]23
= (1/24)(27/3 - 27/3 - 12 + 8/3) = 13/36

9. Sampling & Estimation S2

9.1 Central Limit Theorem

For a sample of size n from population with mean μ and variance σ²:
Sample mean distribution: X̄ ~ N(μ, σ²/n)

This applies even if original population not normal (if n large enough)

9.2 Variance Formulas

Population/sample variance (divisor n):
σ² = (1/n)[Σx² - (Σx)²/n]

Unbiased estimate (divisor n-1):
s² = (1/(n-1))[Σx² - (Σx)²/n]

Use (n-1) when estimating population variance from sample

9.3 Confidence Intervals

For population mean (σ known):
(x̄ - z·σ/√n, x̄ + z·σ/√n)

For population mean (σ unknown, large sample):
(x̄ - z·s/√n, x̄ + z·s/√n)

For population proportion:
(p̂ - z√(p̂q̂/n), p̂ + z√(p̂q̂/n))
where p̂ = r/n

Common z-values:
Confidence90%95%98%99%
z-value1.6451.9602.3262.576
Problem: 87 out of n people have high-speed internet.
Confidence interval: 0.1129 < p < 0.1771
(i) Find n
(ii) Find confidence level α%
Solution:
(i) Midpoint = (0.1129 + 0.1771)/2 = 0.145
87/n = 0.145
n = 600

(ii) 0.1771 = 0.145 + z√(0.145×0.855/600)
0.0321 = z × 0.0144
z = 2.233
Φ(2.233) = 0.9872
α = 2(0.9872 - 0.5) × 100 = 97.44%

10. Hypothesis Testing S2

10.1 Basic Procedure

Steps:
1. State H₀ and H₁
2. Choose significance level
3. Determine critical value(s)
4. Calculate test statistic
5. Compare with critical region
6. State conclusion in context
Null Hypothesis: H₀: μ = μ₀

Alternative Hypothesis:
• H₁: μ < μ₀ (one-tail, decrease)
• H₁: μ > μ₀ (one-tail, increase)
• H₁: μ ≠ μ₀ (two-tail, difference)

Test Statistic: Z = (x̄ - μ)/(σ/√n)

10.2 Critical Values Table

Significance Two-tail (μ ≠ μ₀) One-tail (μ > μ₀) One-tail (μ < μ₀)

2%±2.3262.054-2.054
1%±2.5762.326-2.326

10.3 Type I and Type II Errors

Type I Error: Reject true H₀
• P(Type I error) = significance level

Type II Error: Accept false H₀
• Calculate by finding P(accept H₀ | H₀ false)

10.4 Different Distribution Tests

DistributionTest StatisticNotes
Normal (σ known) Z = (x̄ - μ)/(σ/√n) Exact for normal, approximate for large sample
Normal (σ unknown) Z = (x̄ - μ)/(s/√n) Use unbiased estimate s, large sample
Poisson (large λ) Use normal approximation Apply continuity correction
Proportion (Binomial) Use normal approximation X ~ N(p, pq/n), continuity correction

Approximation Decision Tree

Given Binomial X ~ B(n, p):
• If n > 50 AND np < 5 → Use Poisson: X ~ Po(np)
• If np > 5 AND nq > 5 → Use Normal: X ~ N(np, npq) + continuity correction

Given Poisson X ~ Po(λ):
• If λ > 15 → Use Normal: X ~ N(λ, λ) + continuity correction

Always apply continuity correction when approximating discrete with continuous!

Common Mistakes to Avoid

1. Variance calculations:
• Var(2X) = 4Var(X) but Var(X₁+X₂) = 2Var(X) - not the same!

2. Continuity correction:
• Always use when approximating discrete with continuous distribution
• X > 6 becomes X ≥ 6.5, X ≥ 6 becomes X ≥ 5.5

3. Independence:
• Check P(A∩B) = P(A)×P(B) to prove independence
• Don't assume independence without verification

4. Poisson conditions:
• Mean = Variance is the key property
• When adding: Po(λ₁) + Po(λ₂) = Po(λ₁+λ₂)

5. Hypothesis testing:
• Always state conclusion in context of the problem
• Don't say "accept H₀" - say "insufficient evidence to reject H₀"

6. Quartiles from grouped data:
• Use linear interpolation, don't round n/4 up

7. Regression interpretation:
• 'a' is the y-intercept (value when x=0)
• 'b' is the gradient (change in y per unit change in x)
• Always interpret in context!

Exam Tips & Techniques

General:
• Show all working - method marks available
• Use correct notation: X ~ N(μ,σ²) not X ~ N(μ,σ)
• State distribution clearly before calculating
• Give answers to 3 s.f. unless stated otherwise

Probability:
• Draw tree diagrams or Venn diagrams
• Check probabilities sum to 1
• For "at least" use 1 - P(none)

Normal distribution:
• Always sketch the curve
• Mark mean and required value
• Show standardization step
• Use symmetry when dealing with negative z-values

Poisson:
• Adjust λ for different time intervals
• Remember mean = variance property
• Check if normal approximation appropriate (λ>15)

Hypothesis testing:
• Define symbols used (what does μ represent?)
• State H₀ and H₁ clearly
• Calculate test statistic showing formula
• Compare with critical value
• Give conclusion in context

Confidence intervals:
• State what parameter you're estimating
• Show calculation of point estimate
• Use correct z-value for confidence level
• Give interval as (lower, upper)

Data representation:
• For histograms: remember frequency = area
• For box plots: calculate Q₁, Q₂, Q₃ carefully
• Comment on skewness using quartile positions
• Make comparisons when asked (higher/lower, more/less spread)

Important Inequalities for Discrete Distributions

P(X < r) = P(X ≤ r-1)
P(X > r) = 1 - P(X ≤ r)
P(X ≥ r) = 1 - P(X ≤ r-1)
P(X = r) = P(X ≤ r) - P(X ≤ r-1)

These are crucial for Poisson and Binomial calculations!
